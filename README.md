# Система управления игровой библиотекой

Github - https://github.com/seffax098/gameLibrary

Консольное приложение для учёта личной коллекции видеоигр: хранение списка игр, запись игровых сессий, отслеживание прогресса прохождения, поиск сортировка и статистика библиотеки.

## Назначение

Приложение предназначено для учёта и организации личной коллекции видеоигр:
добавление игр в библиотеку, отслеживание статуса прохождения, сортировка и
поиск по различным критериям (жанр, платформа, год выхода и т.д.).

## Целевая аудитория

- Геймеры, ведущие учёт своей игровой коллекции;
- Пользователи, которым нужно отслеживать статус прохождения игр
- Небольшие сообщества/клубы, обменивающиеся информацией об играх.

## Описание предметной области

Предметная область охватывает хранение и обработку информации об играх,
которыми владеет или интересуется пользователь: их характеристики (жанр,
платформа, разработчик, издатель, год выхода), а также персональные данные
пользователя о взаимодействии с игрой (статус прохождения, оценка, время в
игре, заметки).

## Основные сущности

- **Игра** — название, жанр, платформа, год выпуска, примерное время
  прохождения, оценка пользователя;
- **Игровая сессия** — запись о том, сколько часов и в какой день пользователь играл в конкретную игру;
- **Жанр** — категория игры (RPG, экшен, стратегия и т.д.);
- **Платформа** — платформа, на которой доступна игра;
- **Статус прохождения** — состояние игры (не начата / в процессе / пройдена), вычисляется по сумме сыгранных часов.

## Возможности

- просмотр библиотеки и подробной карточки игры;
- поиск игр по подстроке названия или жанра;
- отбор игр по платформе и году выпуска;
- сортировка по названию, году выпуска, оценке и времени прохождения;
- добавление и удаление игр;
- запись и отмена игровых сессий с подсчётом прогресса прохождения;
- статистика библиотеки: часы, средняя оценка, игры по платформам и статусам;
- справка по функциям проекта, построенная средствами интроспекции;
- сохранение и загрузка данных в JSON-файлах.

## Формат хранения данных

Данные хранятся в каталоге `data/` в формате JSON. Чтение и запись выполняются в модуле `storage.py` через контекстный менеджер `with`; отсутствие файла и некорректный JSON обрабатываются исключениями.

`data/games.json` — список словарей с данными игр:

```json
[
  {
    "id": 1,
    "title": "The Witcher 3: Wild Hunt",
    "genre": "RPG",
    "platform": "PC",
    "release_year": 2015,
    "hours_total": 100.0,
    "rating": 10
  }
]
```

`data/sessions.json` — список словарей с игровыми сессиями:

```json
[
  {
    "id": 1,
    "game_id": 1,
    "date": "2026-09-10",
    "hours": 4.5
  }
]
```

В памяти программы игры представлены словарём `games` (ключ — идентификатор игры, значение — словарь с её данными), а сессии — списком словарей `sessions`. Даты сессий хранятся в файле строками формата `ГГГГ-ММ-ДД` и преобразуются в объекты `date` при загрузке.

## Развитие проекта

Первоначальный сценарий ПР1 работал с одной игрой и отдельными переменными.
В ПР2 данные переведены в коллекции, а функции сценария сохранены в составе
приложения: `get_era()` и `get_rating_label()` — в модуле `games.py`,
`calculate_progress()`, `get_status()` и `make_progress_bar()` — в модуле
`sessions.py`. Карточка игры из ПР1 выводится функцией `show_game_card()`,
которая берёт данные из коллекций и записанных игровых сессий.
